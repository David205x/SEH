# 从主分支删除 V1 且不保留兼容层

当前 V1 可完整运行的混合版本将由 `archive/v1-final` 分支固定保存；主分支随后分阶段删除全部 V1 可执行代码、模板、测试、入口和专用可视化，不增加兼容导入或命令转发。主分支只保留标记为历史档案的 `docs/manual_v1/` 和整体迁入 `runs/archive/v1/evolution/exp_03` 的一份代表性 V1 run；V2 现用的 Intervention 与 rollout/evaluation 行为以最小内部接口脱离 V1，最终接口和命名留到删除完成后的独立整理阶段决定。这样以失去主分支内 V1 可运行性和旧 run 原路径一致性为代价，换取单一活跃实现、较小维护面和清晰的历史恢复边界。
