## 结论性检索观察

1. Candidate-level 评估并非完全“裸分数”：AHE 有预测清单，Self-Harness 有 addressability 和 regression test，HarnessBank 有激活与配对显著性门禁，DREvo 会重校准历史证据。
2. 然而 Meta-Harness、Self-Harness、Harness-R1、TTHE、AHE 与 HarnessBank 的主要行为验证对象仍是已物化的 harness/candidate/patch。
3. Shepherd 和 TraceGraph 已使 prefix fork/replay 成为明确先例；因此 fork 只是实验 primitive，不是本研究可独立主张的创新。
4. HASP 已明确提出 `should_activate + intervene` 的可执行 Program Function；因此 guard/intervention 结构不是首创。
5. “Harness Updating Is Not Harness Benefit”直接证明弱模型的 harness activation/adherence 会失败；HSI 也提出 backbone capability bound，但两者都没有把逐机制 Student realizability 做成编译前 optimizer gate。
6. “Rethinking the Evaluation...”构成强反证：最终实验必须加入预算匹配的 parallel sampling、sequential refinement，以及 disjoint held-out measurement；否则成本或通用收益 claim 不成立。
7. G-Memory 与 Intrinsic Memory Agents 已明确覆盖 cross-trial、agent-specific、role-aligned memory；因此“不同角色只读对应经验”不能单独承担新颖性。
8. LLMA-Mem 的 episodic/procedural/transactive memory 与“已实验方向/教师工作经验/能力边界”高度同构；三分类应被视为设计映射而非原创 taxonomy。
9. Auto-Robotist 已把有正负证据的 search trace 蒸馏成可审计 skill library，并保留探索路径；方向地图的可争取空间是 Harness optimizer 的 typed verification provenance、版本作用域、失效与误剪控制。
10. 因此经验系统应提升为主框架的跨 generation 假设，但不能写成已经成立的收益：必须比较 no-memory、global/shared memory、generic role-local memory 与 verification-grounded role-scoped experience，并测 false pruning。
